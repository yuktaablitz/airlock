Airlock
Inbound firewall for AI agents

Your agent reads everything. Airlock decides what it acts on.

Agents pay invoices, settle claims and run code based on documents written by strangers. Airlock checks every tool result with a fast decision model and removes only the sentences trying to hijack the agent.

How to use this page ↓

What it does

Three things happen to every tool result

Before the agent sees a PDF, web page, API response or image.

1 · See what a human sees

NDI reads the document the way a person would. Text hidden in white or tiny print, or inside an image, is flagged.

2 · Score every piece at once

Drex asks one yes/no question per chunk (“is this aimed at the AI?”) in a single request and answers with calibrated probabilities in a few hundred ms.

3 · Cut only the attack

Only the sentences trying to steer the agent are removed. The rest of the document reaches the agent, so it still finishes your task.

How it’s evaluated

Two questions, measured

Does the agent still work?

Eight industry agents with real tools (pay, trade, settle, prescribe, buy, run). An attack counts only if the agent calls the attacker’s action; checked from tool calls, not by another model. Attacks landed 30% → 0%, tasks done under attack stayed at 85%.

Is each decision right, and can you trust its confidence?

498 test documents never used for tuning. F1 0.971 vs 0.898 for an LLM guard, false alarms 3% vs 83%, and probabilities that match reality (calibration error 0.008).
